# Sprint Reviews

Post-sprint review notes and sync-drift reports for each completed sprint.

## Contents

- `sync-report-YYYY-MM-DD.json` — auto-generated by `sync-issues.mjs` on each docs-sync run; records which Epics were in sync, drifted, or errored
- `sprint-N-review.md` — hand-written sprint review notes (what shipped, what didn't, retrospective inputs)

## Format for hand-written reviews

```markdown
# Sprint N Review — YYYY-MM-DD

**Goal:** [sprint goal]
**Shipped:** [what was completed]
**Carried over:** [what wasn't]
**Retro inputs:** [blockers, surprises, process changes]
```
